# 4. Env

**Done** · updated 2026-10-20 · versions unreleased · milestone: [0.2](milestones/v0-2.md)

## Summary

Environment variables. Code that reads configuration takes an `Env`, so tests set their own and hosts without a
process environment supply a map.

## Design

- **`Env`:** `var(name) -> Option<String>` (`None` when unset or not Unicode) and `vars() -> Vec<(String, String)>`.
- **`SystemEnv`:** `std::env`. On `wasm32-unknown-unknown` nothing is set.
- **`MapEnv`:** variables in a sorted map: `new`, `with` (builder), `set`, `remove`, and `FromIterator`. Clones share
  the map. `JsPlatform` uses one ([spec 7](0007-platforms.md)).
